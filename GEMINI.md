# zeshanmubshir.github.io - Project Context

## Project Overview

This is a personal portfolio and resume website hosted on GitHub Pages. It is based on the [Start Bootstrap - Resume](https://github.com/BlackrockDigital/startbootstrap-resume) theme. The project uses **Bootstrap 4** for styling and layout, **Gulp** for the build process, and **Sass** for CSS pre-processing.

The content in `index.html` showcases a professional profile including sections for About, Education, Publications, Experience, Projects, Skills, Awards, and Interests.

## Tech Stack

* **Frontend:** HTML5, SCSS/CSS, JavaScript
* **Framework:** Bootstrap 4
* **Libraries:** jQuery, FontAwesome, jQuery Easing
* **Build Tool:** Gulp.js (v4)

## Directory Structure

* `index.html`: The main entry point containing all the content.
* `gulpfile.js`: Configuration for Gulp tasks (Sass compilation, JS minification, BrowserSync, etc.).
* `package.json`: Node.js dependencies and scripts.
* `scss/`: Contains source SCSS files. `resume.scss` is the main file which imports other partials like `_variables.scss`, `_nav.scss`, etc.
* `css/`: Contains the compiled and minified CSS (`resume.min.css`).
* `js/`: Contains the source JavaScript (`resume.js`) and the minified version (`resume.min.js`).
* `vendor/`: Third-party libraries (Bootstrap, jQuery, FontAwesome) managed by the Gulp `vendor` task.
* `img/`: Images used in the project (profile pictures, etc.).

## Building and Running

### Prerequisites

* Node.js and npm installed.

### Installation

Install the dependencies defined in `package.json`:

```bash
npm install
```

### Development Server

To start a local development server with BrowserSync (which auto-reloads on changes):

```bash
npm start
```

This runs the `gulp watch` task.

### Build Tasks

The `gulpfile.js` defines several tasks:

* `gulp build`: Runs the full build process (cleans vendor, copies modules, compiles SCSS, minifies JS).
* `gulp vendor`: Copies third-party dependencies from `node_modules` to the `vendor` directory.
* `gulp css`: Compiles SCSS to CSS and minifies it.
* `gulp js`: Minifies the JavaScript.
* `gulp clean`: Deletes the `vendor` directory.

## Development Conventions

* **Styling:** Edit files in the `scss/` directory. Do not edit `css/resume.css` or `css/resume.min.css` directly, as they are generated.
* **JavaScript:** Edit `js/resume.js`. The minified version is generated by the build process.
* **Content:** The website content is static and located within `index.html`.
* **Colors:** Theme colors are defined in `scss/_variables.scss` and `scss/_bootstrap-overrides.scss`.
